## Instructions
Your job is to create a program for your teacher to input student grades into the system.

The program should first ask the user to enter the number of students in their class. (N, for example).

Then, ask the user to input N numbers, representing the average each student got on their paper.

The program will then print out four things in this order:

- The maximum grade
- The minimum grade
- The average (mean) grade (rounded to one decimal place)
- The average (median) grade (rounded to one decimal place, if needed)

**Note:** you do not need to make any functions for this task. Use the `lists` function/methods to complete the task. Look at the Explore for more details. 

### Sample Output
```plaintext
Welcome to the Grade Analysis!
Enter number of students: 5
Enter a grade: 66
Enter a grade: 75
Enter a grade: 81
Enter a grade: 90
Enter a grade: 45
The maximum grade is: 90%
The minimum grade is: 45%
The Average is: 71.4%
The Median is: 75.0%
```
